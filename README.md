# Daravel ![Version](https://img.shields.io/badge/version-alpha--0.0-blue) ![GitHub](https://img.shields.io/github/license/marchershey/daravel)

Daravel, or Default Laravel Application, is a Laravel based application which includes an admin dashboard with user management, role-specific access, content management, & a little more.
